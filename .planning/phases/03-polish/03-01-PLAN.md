## D-05/D-06 Deviation Note

D-05 and D-06 specify `draft: true` YAML frontmatter as the draft exclusion mechanism. **This does not exist in MkDocs** — the mechanism is `draft_docs:` gitignore-style patterns in mkdocs.yml (added in MkDocs 1.6). The plan implements D-05/D-06 intent using the correct mechanism. Document as: "D-05/D-06 implemented via MkDocs 1.6 `draft_docs:` config (per MkDocs docs, frontmatter `draft: true` is not a valid mechanism)."

## edit_uri Clarification

D-07 specifies `edit/main/` path pattern. MkDocs 1.4+ uses `blob/main/` for read-view GitHub links. The plan uses `blob/main/` as it works for all visitors without requiring fork access. Both satisfy SITE-03.
</context>
